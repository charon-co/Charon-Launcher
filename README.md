# Charon Game Launcher

Next-Gen High-Performance Game Launcher with In-App Differential Updates.

## 🚀 Download
Download the latest official installer from the [Releases](https://github.com/charon-co/Charon-Launcher/releases) page.

---

### ✨ Features
- **Ultra-Fast Downloads**: Multi-connection segmented downloads powered by Aria2 engine.
- **Multi-Source Game Library**: Integrated search and catalog browsing across top repositories.
- **Automated High-Speed Extraction**: 7-Zip SIMD multi-threaded decompression.
- **Rich Metadata & Artwork**: HD covers, hero banners, icons, and logos.
- **Automated Save Backups**: Protect game progress with local snapshot archives.
- **Seamless Updates**: Instant in-app differential updates.
